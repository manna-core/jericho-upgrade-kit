# Jericho Memory

Use at the end of a session or after a meaningful discovery.

## Read

- git diff,
- `project-spine/current_state.md`,
- `project-spine/next_steps.md`,
- `project-spine/decision_memory.md`,
- `project-spine/task_state.json`,
- relevant docs changed in the session.

## Update

- Current state: what works, what changed, what was verified.
- Next steps: best next concrete move, next three batches, blockers.
- Task state JSON: phase, active batch, verification booleans, recommended action.
- Decision memory: durable decisions, rejected paths, future warnings.

## Rules

- Do not include secrets.
- Do not include private customer data.
- Keep summaries high-signal.
- Prefer durable project facts over chat diary.

## Output

Report what memory changed and the next recommended move.
