## Product read

- React/Vite frontend,
- Supabase Auth, Postgres, and Edge Functions,
- Vercel hosting,
- Google and Microsoft integrations,
- email/SMS/Telegram workflows,
- AI-driven coaching, prep, summaries, and customer intelligence.

## First install target

```text
/jericho-start
/jericho-safety-pass
```

- full function classification matrix,
